# 出卷与复练

## 课程档案与个人偏好

`records.py init` 的 JSON 至少填写课程名。按已知情况记录考试范围及来源、明确排除内容、考试日期、题型、时长、满分、允许携带的资料、复习时间和资料用途。范围不完整或仅依据课件推拟时标注暂定，不把章节名当作完整课程内容。

用户明确表示某种出卷或反馈偏好希望本课程后续持续采用时，在课程档案的可选顶层 `exam_preferences`、`feedback_preferences` 中保存文字或对象。只针对当前任务的要求用于当前任务。更新这些嵌套字段前先读取旧档案，合并需保留的内容后再写入，因为 `update-profile` 整体替换对应顶层字段。当前请求优先于存档偏好，偏好可以调整默认排版、详略和呈现方式，但不能放松来源依据或评分正确性。

## 出卷资料顺序

优先参考用户提供的练习、作业、教师模拟卷或往年题。没有这些时，优先参考相关 PPT 例题。PPT 有实质性知识内容但没有例题时，可以据此直接出题。已有可用课程参考资料时，不静默混入外部题目。

没有可用于出题的 PPT 且没有其他可用用户资料时，询问用户能否提供教材、笔记等，并等待答复。用户已经明确表示没有，或直接要求联网搜索时，检索对应学科公开考研题作为备选。优先核验出版社、学校等原始发布页面，按用户给出的正式范围与排除项筛选，并在交付试卷前说明采用外部考研题以及其范围和风格尚未按本课程校准。已有资料只覆盖部分范围时，说明缺口并提供有依据的部分练习，若需完整覆盖则请用户补充材料或选择缩小范围。

将核验过的公开题目简要改述为 Markdown，保存原始页面 URL。若原题来源为 PDF，先交给本地转换脚本提取再核验内容。年份、学科和题号仅在来源已核实时记录。按课程导入流程转换并索引，在档案 `source_roles` 将该 Markdown 的来源 ID 标为 `public_grad_exam`。外部题每题保存检索到的实际来源三元组、`basis`、`basis_note` 和来源对象内的 `source_url`，批改与出处说明时逐题引用已验证的 URL。学生版只展示题目及考试说明，保留参考答案和评分细则供批改时使用。

## 出卷依据

新题逐题满足下列一种条件，并填写对应的 `basis` 和非空 `basis_note`：

- `direct` 使用用户提供的 PPT、教材、作业或其他材料中经过核验的实质性课程内容，也可使用用户给出的包含实质依据的详细笔记。符合上述条件时也可使用核验并入库的公开考研题。说明题目如何由具体内容支持。
- `variant` 对用户提供或按上述流程核验并入库的例题作有依据的变式，在用户未要求调整难度时保持原例题的考查概念、解题方法、题设假设及难度层级。说明对应例题、变动与保持的条件。

核验每题属于已知考试范围且不落入排除内容。每题保留实际检索结果中的 `source_id`、`locator`、`chunk_id`，以及可供复核的简要依据。`save-exam` 检查定位三元组存在于新鲜索引中，助手仍须核对引用内容是否真正支持题目和解答。来源是大纲、章节标题或相邻主题，不能单独支持根据课外知识自行补全的题目。

先核对转换警告、缺失页、图表和公式。若现有材料只支撑部分范围，向用户列出覆盖和缺口，提供可溯源的较少题目并标注覆盖范围。若用户要求覆盖整个范围，说明需要补充的材料或细节，按用户选择继续。不能以范围标题推测知识点或借用主题相近的引用补足题数。使用公开考研题时遵守上述检索、核验与说明流程。

## 出卷前

1. 读取课程档案与历史题目，确认本次范围、排除内容、题型、时间及用户偏好。用户未提供的权重和考法标记为未知。
2. 检索并核验每题的具体资料依据，检查其定位和出题依据。变式对照原题检查概念、方法、条件和难度。复测尽量使用能够比较的合规题目。
3. 独立解题，检查条件、数值、单位、合理的多解及题图或数据表是否完整。按照可独立给分的步骤编制评分标准，分项之和应等于题面分值。
4. 保存题库版本后读取学生版，核查题干及附图是否泄露解法，再交付题目。用户指定导出格式时按要求处理。修改试卷用新 ID 并保留与旧版的关联。

## 批改与反馈

原始作答以新的作答 ID 保存，批改覆盖每道题。无法判断的题标记待评及原因，不猜测得分。根据评分细则接受正确的等价解法，说明实际得分与依据。

默认按以下标题和顺序向用户呈现，用户可指定其他格式：

1. **得分**。列出已得分及对应满分，明确待评题和分值，不将待评题计作零分。
2. **错题分析**。按原卷逐题列出错答、部分得分和空答的题目。从作答记录读取 `exam_id`，用 `exam --exam-id` 取原卷，逐字展示保存的原题，包括选项、小问以及所需的已存数据、表格和原题图。原题图或数据没有保存时明确说明缺失，不凭猜测重建。然后按题给出所得分及失分、错误原因、正确解法、知识点和来源。外部题逐题引用核验过的原始页面 URL。每题在自身分析块内直接嵌入与该题有关的带标签图解。即使题目考查相同概念，也各自制作和呈现，不用跨题拼图、共用图或集中图集。图示对照该题题干和正确解核验相对大小、方向、符号和单位，定性图注明不按比例。用户明确要求不使用图时按要求处理。全部正确或仅有待评题时说明结果。
3. **试卷总结**。概括已覆盖范围、优势与薄弱点，提出一至两项下一步行动。适用时询问用户希望继续全面查漏还是专项训练弱项。

### 按失分原因分配解析篇幅

对照原题、评分细则和用户真实作答。必要时引用一行关键公式、判断或已知正确的步骤。说明该步骤表明用户混淆了哪个模型、概念或适用条件。单纯的错误数值通常不足以确定错误来自哪一步。有一个错误带偏多项结果时，先补讲首个有证据的错误，并标明哪些小问受它影响。把已做对的步骤和另外独立的错误分别指出。

- **重点解析**用于失分较多、关键概念用错、解题链断开或多处独立错误。讲清容易混淆的两种条件、如何根据本题识别、从哪一步重新开始，再衔接受影响的小问。知识回顾选自实际暴露的缺口，结合资料出处。图解优先说明引发失分的模型、几何或公式适用条件。
- **简短订正**适合孤立的抄写、单位、符号或运算错误。点明具体偏差、正确值或写法，以及一个能避免重犯的检查点。各题的篇幅按实际需要分配。
- **证据有限**时分别说明空答、有效步骤不足或待评。根据原题提示应识别的条件和第一步。若不同错误解释都合理，把可能卡点标为待核对，避免从一次扣分就断定掌握程度。

例如圆管层流题中，作答若将横向粘性项写成平板的二阶导数，同时用等宽条带积分，优先补讲圆管的轴对称性及圆环面积元 $dA=2\pi r\,dr$。用圆管与平板的截面示意解释几何如何改变方程和积分，再串起速度剖面、流量及截面平均流速。若流态判断正确，明确保留这一正确判断，另外核对雷诺数的取速。遇到同卷只有一次单位漏写的题，指出该单位和检查办法即可。

### 选图与排版

按失分原因选图，让用户从图中看出怎么读题、建立关系或识别适用条件。

- **情景图**适合题设、空间关系或方向弄错的题。用几何轮廓、箭头和标签标出对象、已知量、所求量以及有关的参考方向和边界条件。例如连续性方程题可画粗细两段管口、流向及两个截面，再用图注把截面积与平均流速联系起来。
- **知识点图**适合概念、假设或公式理解有误的题。可以对比两种情形、画出推导关系或用曲线标出决定变化趋势和适用区间的条件。例如用受弯截面的中性轴、两侧拉压和外缘距离解释为什么最大弯曲正应力出现在外缘。曲线有助于读出趋势、阈值或变化原因时也适合做主图。
- 图注点出读图的关键，并把它连到容易犯错的一步。作图本身是题目要求、判断需要读取结果曲线或用户要求绘制结果时，可附结果图。把相关趋势、转折或容易看错的位置在图上标出来。

支持内嵌图片时，用 Markdown 图片语法或平台的图片嵌入方式在题内呈现。使用本地图片文件时填写实际文件路径，确保图片直接显示。多张图按本题小问顺序放置，各自标明题号和小问。图形工具不可用时，可以在该题内用清晰的字符图表达简单关系。

```markdown
### 第 5 题（2／4 分，失 2 分）

**原题**  
逐字展示原题及保存的选项、小问和必要数据。题图随原题展示。

**失分与订正**  
引用作答中的关键步骤，指出失分起点。重点题补讲关键概念和正确起步，小错简短订正。

**知识点回顾**  
围绕作答暴露的缺口说明适用条件，并标注材料页码。

![第 5 题情景图或知识点图](<本题图文件的实际绝对路径>)
```

得分可以用汇总表。交付前逐题核对原题版本、嵌图位置、文件和图注，确认每张图在对应题节正文可见。

依据 `status` 和每次作答的实际证据判断练习表现。样本少、看过提示或刚重复原题时标明判断仍有限。独立完成新的同类题后再调整掌握判断，并结合剩余时间安排后续复测。
