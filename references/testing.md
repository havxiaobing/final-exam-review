# 期末复习技能测试

自动测试使用合成本地课程，运行 `python -X utf8 -m unittest discover -s tests -v`。从技能目录执行。用 [对话用例](../evals/evals.json) 检查助手实际发出的回复和工具调用。

## 对话验收

| 场景 | 通过条件 |
| --- | --- |
| 同一项目内只给课件、作业路径和题型分值 | 先问向量库位置。等待期间，项目、资料目录和模型缓存均没有本次创建的课程文件。 |
| 给了试卷导出位置，项目里还留有别课的向量库 | 仍询问本课程的存放位置。别课的记录保持原样。 |
| 回答一个新的绝对路径 | 继续原任务。Markdown、索引和学习记录写入该课程目录。输出说明实际路径、卷号和可用的题型分值。 |
| 同一门课已有明确存放位置，换会话后补充路径并按卷号交卷 | 恢复原卷和评分细则，追加作答和批改，保留之前的记录。 |
| 明确选择尚未登记的旧目录 | 核对原课程后补登记。旧试卷、作答和批改仍可查询。 |
| 目录里是另一门课 | 停在课程冲突并请用户另选目录。 |
| 给扫描 PDF、图片公式或中英混排课件 | 明确抽取缺失，先依据可验证的内容出题。 |
| 提供老师作业或样题和 PPT 例题 | 优先使用老师提供的题目校准，逐题核对范围、可追溯依据和同类 PPT 的难度。 |
| 没有老师参考题，PPT 有可核验的例题 | 使用 PPT 例题校准，记录对应页和片段，题目不超过同类例题难度。 |
| 只有考纲章节名，或 PPT 没有例题且老师参考题尚未提供 | 说明缺少可核验依据，询问用户能否补充参考资料。尚未明确确认无法提供前，不使用公开考研题后备路线。范围覆盖不全时列明缺项。 |
| 用户明确确认没有可提供的参考题 | 使用合成公开网页测试夹具验证后备流程。仅采用内容可核验且学科、范围匹配的公开考研题，向用户说明来源及链接，存储 `public_grad_exam` 角色与逐题 `source_url`、来源 ID、定位和片段 ID。无法核实时不得编造来源或题目。 |
| 用户要求本卷用表格反馈，且要以后多出老师作业变式 | 得分表只应用于本次，错题节仍带原题和本题图。出题偏好按用户意愿保存，并且每题仍有出处。 |
| 同一考点有两道失分题，其中一道有两个小问两张图 | 每节开头引用本次交卷版本的完整原题。每张图直接嵌在对应题的解析中，图注和内容匹配题号与小问。不同题的图分开。 |
| 静水压力题错误选取深度或面积 | 在本题内画与题面相符的物理情境，标注自由液面、受压面、给定量、未知量及深度参考方向。图解把对应量联系到适用公式，并指出该作答的具体误区。 |
| 混淆深水波和浅水波的适用条件 | 在本题内用概念示意图或概念曲线解释水深与波长的关系及其物理含义。根据课内资料核对近似条件，曲线需标明坐标与适用范围。 |
| 圆管题中写出平板流方程和面积元，另一题仅有单位换算失误 | 引用实际作答中的 `d²u/dy²` 与 `dA=b dy`，结合圆管轴对称条件解释模型选择及 `dA=2πr dr`，认可已正确写出的流态判断。区分最初错误和由它传播的结果，针对前置概念给出正确起步及快速核查。轻微换算错误简洁说明改法，讲解深度依据错误性质和证据调整。 |
| 一题空答、另一题字迹无法辨认 | 保存原作答，明确区分已交卷空答与待评。围绕有证据的题目建议下一步，请用户澄清无法辨认处，避免推断其知识状态，待评题不计入已判得分或掌握度统计。 |

每轮用新会话和独立测试路径运行。记录首次回复、是否调用写入工具、实际写出的文件、试卷版本与题号。先试截图同类的缺路径场景，再补路径走完出卷和批改，能区分对话流程与脚本问题。

## 出题与批改质量

用一组有老师作业、PPT 例题及标准答案的资料做盲评。找同学或由自己独立解一道填空、一道简答和两道计算题，再对照下面几项检查。

- 题型分值符合用户给出的结构，范围内主要考点有覆盖，排除章节没有混进卷面。
- 计算题条件完整、答案和单位正确，难度与对应 PPT 例题可比。抽查每题的原资料页与依据说明，检查例题变式保留考点、解法和适用条件。
- 学生版说明、图题和文件正文不会提示答案。若显式导出 PDF，再抽查分页、公式与中文字体。
- 换一种等价解法进行提交，再交一份漏步骤的作答。应该分别得到满分或可解释的部分分。
- 批改后依次核对得分、错题分析和试卷总结。逐题对照存档原卷核查题干、选项、小问和数据。错题回顾有出处。每张图在其对应题的章节内可直接查看，图中物理量、方向、条件与这道题一致。按原题号找回错题，并确认待评题没有进入已判得分或掌握度统计。检查后续练习是否确实针对重复失分，或覆盖仍未测试的知识点。
- 图解应帮助理解情境、概念或造成错误的原因。涉及受压面、流量或通量的题，检查图中的几何、已知量、未知量和参考方向是否能对应公式。概念曲线可以解释机制、含义或适用条件。用户要求输出曲线或题目本身依赖输出曲线时，可补充最终数值图。
- 评估解释是否引用本次作答中的具体依据，并根据概念性错误、传播性错误或单处笔误调整讲解深度。对关键建模错误检查前提、所需概念、正确起步与快速自检，对轻微错误检查是否清晰指出修改处。避免单凭分数或字数判断反馈质量。

## 发布前的复现

- 在一个临时目录模拟首次安装，使用没有现成模型缓存的环境，按 README 完成初始化。换一位使用者或另一台机器复现一次。
- 缓存模型后再断网运行建库和查询。修订一页 Markdown 后确认旧索引提示重建。
- 把待发布的技能源码单独放进仓库。确认 Git 的待提交列表只包含源码、文档和合成测试，检查其中没有个人绝对路径、课程资料、答案、学习记录、模型缓存或数据库。整理好技能源码的授权声明及第三方依赖的许可证说明。
