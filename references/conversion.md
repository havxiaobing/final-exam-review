# 课程资料转换与检查

转换脚本在本机读取用户明确指定的文件，写入用户指定课程目录的 `materials/`。PDF 需要 Python 包 `pymupdf`，PPTX 需要 `python-pptx`，文本与 Markdown 仅需 Python 标准库。依赖缺失时脚本会报告安装命令。安装方法见项目 README。首次写入前，按 [本地学习记录](records.md) 初始化并确认课程目录。

从技能根目录运行，将尖括号内容替换为实际路径。

```text
python -X utf8 scripts/convert.py --course-dir "<课程目录绝对路径>" "<课程文件路径>" "<另一文件路径>"
```

支持 PDF、PPTX、UTF-8 Markdown 和 UTF-8 文本。旧版 `.ppt` 可以先在 PowerPoint 中另存为 `.pptx`，再指定该副本转换。每个文件生成一个 Markdown，输出 JSON 给出状态、输出位置、空白页或幻灯片以及转换局限。Markdown 标题记录原文件名，二级标题 `## Page N`、`## Slide N` 或 `## Section N` 记录来源位置。

PDF 依靠文字层抽取。扫描页需要 OCR 或人工转写。PPTX 文字和表格按尽力推测的阅读顺序抽取，图片、图表、嵌入对象、演讲者备注和公式可能缺失。PDF 的公式、表格、图像及排版也可能不完整或乱序。根据警告及课程内容的重要性检查转换结果，必要时请用户依据原资料补充图示、公式与表格。空白或内容不完整的资料不能作为完整覆盖考试范围的依据。

在 `materials/` 内编辑生成的 Markdown 可修正内容。保留文件的一级标题及 `## Page N` 或 `## Slide N` 等二级定位标题，以便检索结果可追溯。检查或修改后重新构建索引。也可以把独立的人工整理内容作为新的 UTF-8 Markdown 显式输入，再进行转换和索引。

同一个来源路径重复转换时默认保留现有 Markdown，保护手工修订。源资料确有更新时先备份或合并修订，再使用 `--overwrite` 重新转换并更新索引。全部内容抽取为空或转换失败时，已有 Markdown 会保留。文件移动或改名后会获得新的来源标识，需留意旧资料与新资料重复索引。
